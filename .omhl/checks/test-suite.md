Runs `cargo test --workspace --lib --release --locked -- --test-threads=4` with `TMPDIR=/dev/shm`, so the temporary files of the tests stay in memory and at most 4 tests run at once (the pre-push budget is 4 cores); it passes when every unit test under `crates/*/src` (the `tests.rs` files next to the sources) passes. The tests under `crates/*/tests` (the `integration` and `e2e` groups) and the doctests run only in CI (`.github/workflows/ci.yml`), which blocks the merge.
